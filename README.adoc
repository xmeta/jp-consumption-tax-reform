= 日本の消費税改革研究
:lang: ja
:revdate: 2026-09-13

本リポジトリは、日本の消費税改革を「税率ありき」ではなく、明示した社会目的の下で評価する研究の正本である。
政策目的と政策手段を分離し、識別できない数量を0や点推定として政策結論へ使わない。

== まず確認する場所

科学的状態のauthority orderは次の通りである。

. `data/scientific_state.csv` — module-level scientific state / blocker
. `data/claim_graph.csv` — claim-level authorityとproduct projection
. `STATUS.adoc` と各module README — human-facing mirror
. GitHub Issues / Pull Requests / Project — 作業管理。上位の科学的authorityを上書きしない

詳細な契約は link:docs/scientific_state.adoc[Machine-readable Scientific State] を参照する。
現在のactive componentは全て `policy_usable=false` であり、直接のpolicy optimizer inputとしてREADYなcomponentはない。

== Active scientific-state dashboard

以下は `data/scientific_state.csv` のactive rowsを簡潔に表示する。長いblocker説明はここへ複製しない。

[cols="2,4,2,1"]
|===
|Component |Detailed status |Maturity |Policy usable
|income_tax_pseudofiler |SENSITIVITY_ONLY_REPRODUCED |SENSITIVITY_ONLY |false
|income_tax_partial_identification |MODEL_CONTINGENT_RANK_ONE_SIDED_BRIDGE_REPRODUCED |SENSITIVITY_ONLY |false
|stage1_filing_bound |ROBUSTNESS_FRONTIER |PARTIALLY_IDENTIFIED |false
|vat_compliance_productivity |MODEL_CONTINGENT_COMPLIANCE_PRODUCTIVITY_SENSITIVITY |SENSITIVITY_ONLY |false
|vat_policy_integration |SCENARIO_SCHEMA_INTEGRATED_WITH_STATIC_REFERENCES_AND_UNRESOLVED_MACRO_OUTCOMES |PARTIALLY_IDENTIFIED |false
|===

用語上、`REPRODUCED` は再生成可能であることを示し、因果識別や政策利用可能性を意味しない。
`MODEL_CONTINGENT` / `SENSITIVITY_ONLY` は仮定・感度条件付き、`NOT_IDENTIFIED` / `NOT_READY` は未識別・未準備を示す。
`RECOVERY_ONLY` は回復用証拠でありactive reproduced claimの単独根拠にはしない。

== Current high-value blocker

VATのobjective-rank household incidence bridgeは、2024 NSFCW `DS51` ↔ `DS52` のprovider-approved same-household joinが未確認であるため未識別を維持する。
作業ownerは https://github.com/xmeta/jp-consumption-tax-reform/issues/94[Issue #94]。provider確認なしにjoin keyを推測しない。

その他の研究優先順位は `data/research_priority_backlog.csv`、作業順は https://github.com/users/xmeta/projects/1[GitHub Project #1] とmilestone `M3 Research governance and publication readiness` を参照する。
