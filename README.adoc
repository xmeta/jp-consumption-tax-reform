= 日本の消費税改革研究
:lang: ja
:revdate: 2026-09-10

本リポジトリは、日本の消費税改革を「税率ありき」ではなく、明示した社会目的の下で評価する研究の正本である。

== 現在の原則

* 目的と政策手段を分離する。
* 実質経済成長率は各年で 0% を上回ることを優先し、成長率の低下も可能な限り避ける。
* 所得・資産・世代間格差、貧困、二乗貧困ギャップ等を厚生評価へ入れる。
* 特定の消費税率や 3% インフレを目的化しない。
* 識別できない数量を点推定として論文の政策結論へ使わない。

== 再現

研究者がローカルで使う再現経路とCIは `scripts/reproduce.py` に統一している。

[source,shell]
----
python -m pip install -r requirements-research-lp.txt
python -m pip install -r requirements-data-extraction.txt
python scripts/reproduce.py --list
python scripts/reproduce.py paper1
python scripts/reproduce.py vat
python scripts/reproduce.py all
----

release前のclean-room再現では、追跡済み生成物を一時worktree内で削除して再生成し、manifest・provenance・生成差分・clean treeまで検証する。

[source,shell]
----
python scripts/reproduce.py clean-room
----

Ruby/Asciidoctorを含む前提環境、各target、CI契約の詳細は link:docs/reproducibility.adoc[再現性・完全性契約] を参照する。
