= 日本の消費税改革研究
:lang: ja
:revdate: 2026-09-08

本リポジトリは、日本の消費税改革を「税率ありき」ではなく、明示した社会目的の下で評価する研究の正本である。

== 現在の原則

* 目的と政策手段を分離する。
* 実質経済成長率は各年で 0% を上回ることを優先し、成長率の低下も可能な限り避ける。
* 所得・資産・世代間格差、貧困、二乗貧困ギャップ等を厚生評価へ入れる。
* 特定の消費税率や 3% インフレを目的化しない。
* 識別できない数量を点推定として論文の政策結論へ使わない。
