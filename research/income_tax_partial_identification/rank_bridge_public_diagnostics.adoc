= Public diagnostics for weakening the F71561-to-NTA rank bridge
:toc:

== Status

This file records public-data diagnostics *before* any v3 transport-result
calculation.  The diagnostics do not identify a cross-system rank map and are
not used as hard equality constraints between the National Survey of Family
Income, Consumption and Wealth (NSFCW) and National Tax Agency (NTA) data.

The purpose is narrower: document observable heterogeneity within the NSFCW
rank system, preserve the official source files, and make later rank-transport
sensitivity assumptions auditable.

These are within-NSFCW composition facts.  They are not NTA filer shares.

== Why no NTA category equality is imposed

The NSFCW categories are not a one-to-one partition of the NTA Table 2-2(1)
primary-income-earner categories.  In particular:

* NSFCW "wages and salaries" is conceptually related to NTA salary but is not
  asserted to define the same unit or population;
* NSFCW "business and homework income" is not asserted to equal the NTA
  business-primary category;
* NSFCW property income is broader than the NTA real-estate-primary label;
* NSFCW current transfers can contain pension-type income, but it is not
  identical to the NTA miscellaneous-primary category;
* the NTA residual "other" primary category has no direct NSFCW counterpart in
  this four-component source partition.

Therefore neither extracted table supplies an observed cell-by-cell NTA
crosswalk.  Any such crosswalk would be an additional model assumption.

== Consequence for v3 design

The core v3 bridge should weaken exact same-rank correspondence using a
transparent rank-transport budget and should report a robustness surface over
that budget.  These public diagnostics can justify treating exact rank
correspondence as nontrivial and can support interpretation, but they should
not be used to select a single transport budget after seeing tax-incidence
outcomes.

A category-constrained bridge, if studied later, must be registered as a
separate sensitivity specification with its own explicit crosswalk uncertainty.
