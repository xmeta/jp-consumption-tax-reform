= NTA Non-resident Filing Source Audit
:revdate: 2026-09-08

== Question

Can published NTA aggregate statistics directly identify or upper-bound the
number of non-resident persons included in the FY2024 final-return count?

== Finding

No direct resident/non-resident final-return person cross-tab was found in the
official published tables examined for this audit.

This is a source-availability finding, not a claim that NTA has no such
administrative data internally.

== Exact numerator

The FY2024 NTA Annual Statistics Report, table 2-1(1), reports:

* total self-assessment / cases processed actual persons: `23,362,184`;
* final-return persons: `23,090,075`;
* amended-return persons: `145,620`.

The stage-1 benchmark uses the exact `23,090,075` final-return row rather than
the broader cases-processed total.

== Published table coverage examined

The FY2024 self-assessment income-tax chapter publishes taxation status,
income-range counts, income-type counts, and prefectural tables. The published
taxonomy examined here does not expose a residence-status dimension.

The withholding-income-tax chapter separately publishes statistics on
non-resident income, but those tables report payment and withholding-tax
amounts rather than a deduplicated count of non-resident self-assessment
final-return persons.

NTA guidance confirms that non-residents can have Japanese final-return
obligations for domestic-source income, so the non-resident component cannot be
set to zero.

== Role in the robustness frontier

Non-resident final-return filers outside the Census/resident bridge are one
possible component of the total untracked mismatch budget stem:[C_U].

They are not equated with stem:[C_U]. Other timing, survey-eligibility,
household-frame, or population-definition mismatches can also contribute.

No point value is imputed to the non-resident component.

== Scale diagnostic: treaty information exchange

The NTA FY2024 treaty-information-exchange report states that Japan provided
`920,649` statutory-report information records to foreign tax authorities
concerning payments to non-residents.

This is useful only as a scale diagnostic. It is not an upper bound on
non-resident final-return persons because it counts information records, not
deduplicated final-return filers, and its coverage differs from the
self-assessment population.

Therefore `920,649` is not used to set or reduce stem:[C_U].
