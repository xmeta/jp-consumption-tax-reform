== Stage-1 filing-participation robustness frontier

The first selection step asks how strongly the public survey-frame benchmark
can constrain overlap with the NTA Table 2-1 Final-return processing-row benchmark.

We do not estimate a filing probability by pseudo-filer fitting. We first form
a nominal overlap benchmark and then expose all additional untracked
population/frame mismatch as an explicit budget.

=== Published frame benchmark

Let stem:[F={stage1-final-return-filers}] denote the observed NTA FY2024
Table 2-1 Final-return processing-row count, stem:[P={stage1-candidate-upper}] the entire 2020 Census
population used as a deliberately loose person denominator, and
stem:[M_0={stage1-mother-benchmark}] the published F71561 mother-population
frame benchmark reconstructed from the 2020-Census-based survey design.

|U1 |stem:[C_U] additional overlap loss |Unresolved mismatch budget |Includes non-resident and any other untracked frame/timing/eligibility mismatch
|===

Under exact set correspondence, the nominal Fréchet overlap benchmark is

[stem]
++++
B_0 =
\max\{0,F-(P-M_0)\}
=
{stage1-nominal-overlap}.
++++

This quantity is a benchmark, not an unconditional identified overlap.

=== Tracked mismatch allowance

To avoid optimistic alignment assumptions, we allocate several observable
population-timing channels entirely against the nominal overlap:

* all 2020--2024 births: stem:[3{,}836{,}677];
* all 2020--2024 gross international inflows: stem:[2{,}643{,}204];
* every 2024 death as one potential quasi-final return:
  stem:[1{,}605{,}378].

Their sum is

[stem]
++++
D={stage1-tracked-allowance}.
++++

This allowance is intentionally adverse. The categories can overlap, many
persons are not filers, and the full-year 2020 counts include events before
the Census reference date.

After allocating stem:[D], the residual benchmark is

[stem]
++++
B_R =
\max\{0,B_0-D\}
=
{stage1-residual-benchmark}.
++++

At zero additional untracked mismatch, this corresponds to a benchmark rate of
{stage1-robustness-rate-cu0-pct}%.

=== General untracked-mismatch frontier

Let stem:[C_U\ge0] be an analyst-specified upper budget for further reduction
in the nominal overlap. The reproduced robustness function is

[stem]
++++
R(C_U)=
\frac{\max\{0,B_R-C_U\}}{P}.
++++

For any externally supplied admissibility threshold stem:[A\in[0,1]], the
benchmark-adjusted rate remains above stem:[A] whenever

[stem]
++++
C_U<C_U^*(A),
\qquad
C_U^*(A)=\max\{0,B_R-PA\}.
++++

This is the main stage-1 result. The function stem:[C_U^*(A)] gives the exact
break-even mismatch budget implied by the public-data benchmark for any
externally supplied threshold. It does not identify the actual value of
stem:[C_U] and therefore does not unconditionally reject any threshold.
