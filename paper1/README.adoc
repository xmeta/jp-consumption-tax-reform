= Paper 1 build notes

This directory contains the first-submission manuscript only.

It does not claim an optimal VAT rate, a structural macro effect, a
point-identified filer MTR distribution, or an unconditional filing-rate lower
bound.

The paper asks which identification and robustness statements remain defensible
when reproducible public aggregate data are available but filer microdata are
not.
