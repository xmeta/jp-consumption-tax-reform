= Paper 1 build notes

This directory contains the first-submission manuscript only.

It does not claim an optimal VAT rate or a structural macro effect.
The paper asks what can be identified about Japanese personal income-tax
marginal incidence using public aggregate data when filer microdata are not
available for redistribution/reproduction.
