= 目的関数と政策手段
:revdate: 2026-09-10

== 目的

政策の「善」は税率そのものではなく、実体・分配・貧困の結果で定義する。

主要な評価対象は、実質所得・生産 (Y) の増加、所得格差 (G_Y) と資産格差 (G_W) の縮小、世代間格差 (Gap_{Age}) の縮小、貧困指標の改善である。
特に二乗貧困ギャップ (P_2) を含める。

実質成長率 (g_t) については、各年 (g_t>0) を強く優先し、
((g_{t-1}-g_t)_+) により成長率の低下も罰する。

重みをまだ固定しない一般形は

[stem]
++++
L=sum_t[
 w_-(-g_t)_+^2+
 w_Delta(g_{t-1}-g_t)_+^2+
 w_{P2}P_{2,t}+
 w_Y G_{Y,t}+
 w_W G_{W,t}+
 w_A Gap_{Age,t}
]+	ext{constraint penalties}.
++++

== 手段

政策ベクトルは税率と制度状態を分離する。例として

[stem]
++++
p=(t_{VAT},s_{VAT}^{admin},lambda,\tau_Y,\tau_A,S_Y)
++++

とし、stem:[t_{VAT}] は消費税率、stem:[s_{VAT}^{admin}] はVAT固有の計算・仕入税額控除・インボイス・申告等の行政制度状態を表す。

したがって +VAT rate = 0%+ と +VAT制度の完全廃止+ は同一政策ではない。
税率を0%へ下げても制度を維持するシナリオでは、VAT固有事務の解放を自動的に仮定しない。

制度廃止による生産性チャネルは、通常の需要効果と分離して

[stem]
++++
\Delta y_{institution}
=
m(s_{VAT}^{admin})
\left(
\rho c_{VAT}+a_{alloc}
\right)
++++

と表すことができる。ただし stem:[c_{VAT}]（VAT固有実資源費用率）、stem:[\rho]（生産的再配分率）、stem:[a_{alloc}]（配分効率利得）は現時点で点識別されておらず、感度分析入力としてのみ扱う。

給付・還付、所得税、資産課税、所得支援等も政策手段として扱う。
インフレ、金利、JGB市場機能、利払い、為替は目的そのものではなく状態・副作用・制約として扱う。
VAT廃止時の減収をJGB・所得税・資産課税等のどれで補うかも、コンプライアンス生産性チャネルとは別の政策手段である。
== 実装上の政策シナリオ接続

Issue #26 のVAT制度廃止チャネルについては、
+research/vat_policy_integration/+ が上記の「目的」と「手段」を混同しないための
最小統合層を提供する。現行8/10%、5%、0%+VAT行政維持、完全廃止、
完全廃止+JGB、所得税改革、資産課税、混合財源の8政策を同一schemaへ載せる。

現時点で数値化されるのは、VAT制度完全廃止時だけ発生する
stem:[m(\rho c_{VAT}+a_{alloc})] のstress componentとそのtransition-growth
contributionである。overall GDP、年次成長率、Gini、FGT2、財政、債務等は、
対応する需要・家計帰着・財源モジュールが再現可能になるまで空値と
識別statusを併記する。未実装チャネルをゼロと仮定しない。

財源側では、財務省のFY2024国庫歳入実績から中央政府の消費税収納済歳入額
25.021206715兆円を静学的な置換対象referenceとして接続する。これは改革後の
税収予測や財政収支ではなく、0%化/完全廃止時の粗い財源規模を示す基準値に
限定する。5%化は10%/8%税率構成・課税ベース・行動反応を要するため、総税収を
単純比例させない。

JGB全額調達シナリオについては、内閣府2024年度国民経済計算の名目GDP
642.4147兆円を分母に用い、25.021206715兆円のgross financing referenceが
FY2024名目GDPの3.894868333%に相当することまでを静学的に報告する。ただし、
これは既存債務残高、償還、金利、名目GDP反応を含むdebt/GDP変化ではない。

分配側では、2024年全国家計構造調査表1-21から年間収入十分位別の月次消費支出と
10大費目を観測diagnosticとして接続する。月次消費支出は年間収入十分位1で
129,460円、十分位10で439,645円である。ただし、この順位は世帯年間収入十分位で
あり、目的関数で用いるOECD新基準の等価可処分所得十分位ではない。また表の「食料」
には酒類・外食が含まれるため8%軽減税率対象額とは扱わない。したがって有効なrank
bridgeとVAT帰着モデルが成立するまでは、Gini、FGT2、十分位別実質可処分所得の政策
効果は空値のまま保持する。
