= 識別境界
:revdate: 2026-09-08

== 原則

集計公表データから識別できる対象と、構造仮定を必要とする対象を分離する。
点識別できない量は部分識別・感度分析・外部較正として表示する。

== 所得税

F71561の所得十分位×世帯類型セルは、世帯主・配偶者・その他構成員の賃金等を含むが申告者ミクロデータではない。
したがってpseudo-filer再構成は真の法定限界税率分布を識別しない。

pseudo-filerは、2026年税制を適用し、観測F71561所得税額モーメントへdecile別nuisance scaleを較正する診断である。
nuisance scaleは欠落所得・控除等を吸収する較正装置で、行動・因果パラメータではない。

NTA給与階級データを用いる社会保険料・扶養控除構成も外部感度分析であり、世帯十分位との対応は未識別である。

== 使用規則

* SENSITIVITY_ONLY はETI等の感度帯には使える。
* NOT_READY は最適政策を一点で決める入力に使わない。
* READY_STATIC_ONLY は静学的税額・分配効果を越えて行動反応へ外挿しない。


== F71561 stage-1 filing participation

2026-09-08時点で、申告参加率を点識別したとは主張しない。
代わりに、母集団外申告者数を contamination parameter stem:[C] として残した
部分識別・頑健性フロンティアを構築した。

2020国勢調査、2024全国家計構造調査の標本設計、2024申告所得税統計を
保守的に接続すると、追加contaminationをゼロとした下限は15.4096%となる。
ただしこれは stem:[C=0] の条件付き値である。

V6の +score_power=2.0+ 閾値2.20%を棄却不能にするには、
母集団外申告者が16,663,383件必要である。
2020--2024年の出生・国外転入を全件、2024年死亡を全件準確定申告とみなす
極端な上限8,085,259件を差し引いても、さらに8,578,124件の未追跡
contaminationが必要となる。

従って、この結果は +score_power=2.0+ に対する強い頑健性診断であるが、
非居住者申告者等の上限が閉じるまでは正式な識別下限へ昇格しない。
+income_tax = NOT_READY+ は維持する。


=== Candidate-person denominator coverage

stage-1の分母はpseudo-filer数ではなく、2020国勢調査の全人口126,146,099人を
上限として使う。個人所得税の候補単位は個人であるため、静的Census frame内の
候補人数は全人口を超えない。この置換は申告参加率の下限を弱める方向にしか働かない。

従ってcandidate-person coverage条件はこの保守的定式化では閉じる。
残る主要未識別量は、非居住者等のCensus/resident frame外確定申告者
stem:[C_{NR}] である。
