= Research Prioritization: Expected Value of Information and Stop Rules
:revdate: 2026-09-11

== Authority and purpose

`data/research_priority_backlog.csv` is the machine-readable queue for unresolved
research gaps.  It does not replace `data/scientific_state.csv`: scientific
status remains authoritative there.  The backlog answers a different question:
which unresolved gap should receive the next unit of research effort?

The queue deliberately does not use source count, file count, or stress-grid
size as progress metrics.  More evidence is valuable only when it can plausibly
shrink a decision-relevant admissible set, establish a missing linkage, or
complete a model required for comparing policy scenarios.

== Qualitative VoI rubric

No pseudo-precise expected-value number is assigned when probabilities and loss
functions are not identified.  Each gap is ranked using four explicit judgments:

* `decision_impact`: whether resolving the gap can change a policy ranking or a
  material manuscript claim;
* `expected_identification_gain`: whether the proposed evidence/method can
  plausibly turn an unlinked quantity into a direct estimate/bound or materially
  shrink the current admissible set;
* `expected_effort` and `access_delay`: implementation/access cost that reduces
  the value of working on the gap now;
* `expected_voi`: the resulting qualitative ordering (`HIGH`, `MEDIUM`, `LOW`).

`priority_rank` is the operational order, not a claim that the categories are
cardinal utilities.  Within a VoI class, reversible judgment is allowed and the
CSV should be updated when new evidence changes feasibility or decision impact.

== Identification gain versus evidence accumulation

`identification_gain_type` separates `DIRECT_OR_BOUND_SHRINKAGE`,
`BOUND_SHRINKAGE`, and `MODEL_COMPLETION` from mere evidence accumulation.
A new survey, paper, or descriptive statistic that does not change a linkage,
bound, counterfactual, or model-required state is not automatically progress.

The `evidence_accumulation_only` flag must be explicit.  A candidate classified
as evidence accumulation only cannot receive `HIGH` expected identification
gain or `HIGH` expected VoI.

== Stop rules

Every row has a `stop_rule`.  Public-data searches marked
`STOP_PUBLIC_SEARCH_ESCALATE_RESTRICTED` are closed as public-source dead ends
unless a new source satisfies the exact missing-link condition in that row.
`STOP_UNLINKED_EVIDENCE_ACCUMULATION` prohibits adding more disconnected
burden/incidence sources that do not tighten the target parameter or bound.

Stopping public search is not equivalent to setting the unknown quantity to
zero.  The row must instead name an escalation path: restricted/admin data,
secure/custom tabulation, formal sensitivity analysis, or retention of the
current `NOT_IDENTIFIED`/partial-identification state.

== M2 VAT decision-readiness boundary

M2 completion means the repository can state what is identified, what is only
model-contingent, and where further public-data work has hit an explicit stop
rule.  It does *not* mean that Japan's optimal VAT policy, national compliance
productivity dividend, policy pass-through, objective-rank Gini/FGT2 effects, or
endogenous JGB-market response have been point identified.

The eight-scenario matrix and Pareto screen remain valid negative-identification
outputs: required welfare objectives are missing numerical bounds, so no scenario
is promoted to an optimal or robustly non-dominated policy.  Future restricted or
prospective data can shrink those sets through dedicated follow-up issues without
keeping the M2 public-data search open indefinitely.

== Validation

Run:

----
python scripts/validate_research_priority.py
python scripts/test_research_priority.py
python scripts/validate_repo.py
----

The validator checks schema, unique consecutive priority ranks, allowed ordinal
values, Issue #25/#26 coverage, stop-rule/escalation discipline, and the
separation between identification improvement and evidence-only accumulation.
